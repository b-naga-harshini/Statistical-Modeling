Implemented Linear Regression on the cleaned Supply Chain dataset to predict Revenue Generated. # Week 4 – Implementation of Statistical Modeling

## Project Overview

This project focuses on implementing a statistical model using the cleaned Supply Chain dataset. Linear Regression was selected to analyze the relationship between supply chain factors and Revenue Generated.

## Objectives

* Select a suitable statistical model.
* Prepare the dataset for modeling.
* Select relevant numerical features.
* Split the data into training and testing sets.
* Train and test the Linear Regression model.
* Evaluate model performance.
* Perform 5-fold cross-validation.
* Analyze predictions and residuals.

## Model Used

**Linear Regression**

### Target Variable

* Revenue Generated

### Predictor Variables

* Price
* Number of Products Sold
* Stock Levels
* Lead Times
* Order Quantities
* Shipping Times
* Shipping Costs
* Production Volumes
* Manufacturing Lead Time
* Manufacturing Costs
* Defect Rates
* Costs

The model was evaluated using:
